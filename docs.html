海畔使用文档

对应海畔 Android 当前发布版本。本文按安装、登录、课表、成绩与考试、空教室、提醒、校外访问的顺序，说明各项功能的实际行为与限制。

01

安装与更新

海畔以 APK 形式分发，适用于 Android 8.0 及以上、arm64 设备。应用未上架应用商店，安装前需要在浏览器或文件管理器中允许「安装未知来源应用」。

  1. 获取安装包从官网下载区或 GitHub Releases 下载 haipan-app-release.apk。下载页固定指向最新正式版本，不需要手动查找版本号。
  2. 覆盖安装正式版使用同一签名，可直接覆盖旧版本。课表缓存、设置与登录状态会保留，无需先卸载。
  3. 确认版本安装后进入「我的 → 关于」查看应用版本与构建版本。这两项均来自安装包本身，而不是应用内写死的常量。
只从官方渠道下载
请使用官网、GitHub Releases 或 Gitee 镜像。第三方站点重新打包的 APK 可能被篡改，签名不一致时也无法覆盖安装。

应用启动时会自动检查一次更新，也可以在「我的 → 检查更新」手动触发。客户端读取 GitHub 最近一次正式 Release 的标签，与安装包版本比较：主版本号相同的前提下，构建号更大才会提示更新；只有同时存在可下载的 APK 资产时才会弹出更新提示。

02

首次登录

登录通过学校统一身份认证完成。海畔在应用内提交学号、密码与验证码，密码经原生加密后发送，不经过第三方服务器；认证成功后只保留教务会话 Cookie。

  1. 优先连接校园网校园网内直连教务，速度最快，也不需要额外开通公网通道。
  2. 完成统一认证按认证页提示输入学号与密码，并完成验证码、短信或企业微信等多因子步骤。
  3. 等待数据导入首次登录会拉取课表与学籍信息。导入完成后进入首页，之后可在各页面切换学期查看历史数据。
校外首次登录
公网通道需要管理员按学号开通。未开通时，请先连接校园网完成首次登录，再在校外使用。

设备绑定与换机

首次登录会把学号与当前设备的密钥绑定。私钥由 Android Keystore 生成并保存在本机，服务端只登记公钥。正常换机后重新登录即可自动换绑，旧设备的会话随即失效；如果管理员关闭了自动换绑，需要先在旧设备退出登录，或联系管理员重置绑定。

游客浏览

未登录时仍可进入应用查看已缓存的课表。没有缓存时只显示空状态，不会向教务系统发起请求。

03

课表

首页展示当前学期的周课表。顶部学期选择器用于切换学期，周次条用于切换周次，进入页面时默认定位到本周。

周次与学期

周次根据开学日推算。估算与实际不符时，可在「设置 → 开学周起始日期」校准，也可以直接切到正确周次。历史学期可以随时回看，但日期标签只对当前学期显示。

课程信息

点击课程卡片可以查看课程名、教师、教室、节次、周次与课程性质。没有固定节次的实践课会单独列在课表下方，不会强行放入网格。同一门课在整张课表中保持固定颜色，切换学期后重新分配。

离线缓存

每个学期的课表独立缓存。成功加载一次后，断网或会话过期时仍能打开最近一次结果；下拉刷新会先展示缓存，再在后台同步在线数据。切换账号会清空课表缓存，避免不同账号的数据混在一起。

课程提醒
课表同步后会按本地缓存排程上课提醒。提醒时间与开关在「设置 → 提醒」中调整，断网状态下也能触发。
04

成绩与考试

成绩与考试按学期组织，页面顶部可以切换学期。默认进入当前学期；如果当前学期暂无数据，会自动回退到最近一个有数据的学期。

成绩总览

总览显示学分绩点、加权平均分、已获学分与通过情况，并按课程性质和分数区间给出分布。绩点按学校规则在本地换算，标注「估算」的数值仅作参考，最终结果以教务系统为准。

成绩明细

课程明细包含学分、绩点、成绩与课程性质。展开单科可以查看平时、期末、总评等成绩构成；分项数据首次需要在线获取，之后从本地缓存读取，手动刷新会重新同步。

考试安排

考试按时间排序，显示倒计时、起止时间、考场与座位号。考试提醒与上课提醒分别控制，可以只开启其中一项。点击考试卡片可以查看完整安排。

05

空教室

空教室查询用于临时寻找自习位置。数据来自教务排课结果，反映的是排课层面的空闲状态，不等同于现场门禁或实际占用情况。

  1. 选择范围先选校区、楼号和教室类别，再指定周次、星期与节次。条件越具体，结果越接近实际。
  2. 查看结果结果区分可用与占用，并显示教室名称、容量等信息。可用教室排在前面。
  3. 收藏常用教室收藏后会排在结果前面，也可以单独查询某间教室在指定时段的使用情况。

教务端对多选条件按「同时空闲」处理，条件越多结果越少。海畔在结果为空时会按单个时段分别查询并合并，查询耗时会相应增加；客户端同时做了限速，避免短时间高频请求。

以现场为准
临时调课、考试占用或教室关闭不会实时反映在排课数据中，出门前建议再确认一次。
06

提醒与桌面组件

提醒依赖系统通知与精确闹钟。首次开启时需要授予通知权限；Android 12 及以上还需要「闹钟与提醒」权限。部分厂商系统要求额外允许自启动与后台运行。

上课与考试提醒

提醒在课表同步后按本地缓存排程，断网也能触发。点击通知会直接打开对应课程或考试。上课与考试的提前时间可以分别调整；系统省电策略可能造成延迟，建议把海畔加入电池优化白名单。

桌面组件

提供「今日课表」与「课表 + 考试」两种组件。添加方式与普通 Android 组件一致：长按桌面空白处 → 组件 → 海畔。组件数据由应用同步写入，打开一次应用即可刷新。

组件不刷新时
先打开一次应用，让课表与考试完成同步。部分系统会限制后台组件刷新，重新添加组件通常可以恢复。
07

校外访问

应用会在启动和网络变化时自动探测教务连通性。校园网内直连教务；在校外且已开通公网通道时，自动切换到加密中转链路，无需手动设置。

校园网
直连教务，速度最快，推荐优先使用，也不占用公网通道资源。
公网通道
按学号开通，经加密隧道回到校园网。速度受中转链路和学校出口影响，适合临时查看课表与成绩。
切换方式
自动探测并在网络变化后重连。连接失败时会尝试切换到其他可用入口。
认证要求
通道只解决网络可达性，不改变学校统一身份认证的多因子要求。
通道不是万能入口
如果校外登录持续失败，请先回到校园网完成认证，或联系管理员确认学号是否在准入名单内。
08

常见问题

登录提示未开通或设备不匹配

先确认当前是否在校园网。在校外使用时，需要管理员把学号加入公网准入名单。提示设备不匹配，说明该学号已绑定其他设备：可以等待自动换绑，或联系管理员重置后重新登录。

课表为空，或周次与实际不符

先在课表页下拉刷新，确认学期选择正确。周次偏差通常是开学日估算问题，可在设置中校准开学周起始日期，或直接切到正确周次。历史学期不显示日期属于正常现象。

提示有更新，但安装包已经是最近的

在「我的 → 关于」核对构建版本。客户端只在最新 Release 的构建号大于安装包构建号时提示更新；如果两者一致仍有提示，请在意见反馈中附上运行日志，便于定位。

换手机后需要重新登录吗

需要。新设备首次登录会重新完成设备认证，本地缓存不会跨设备迁移，课表与成绩会重新从教务系统拉取。

提醒没有触发或明显延迟

依次检查通知权限、「闹钟与提醒」权限和系统省电策略。部分国产系统还需要单独允许自启动与后台运行。修改权限后，重新打开应用并刷新一次课表，让提醒重新排程。

如何反馈问题

进入「我的 → 意见反馈」，应用会自动导出机型、系统版本与脱敏后的运行日志，并作为附件填入邮件。需要更详细的日志时，可在「我的 → 关于」连续点击应用版本 5 次开启调试入口，再进入「调试」调整输出详细日志与日志保留天数。也可以直接发送邮件到 xiuhong0327@163.com。
