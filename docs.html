01

安装与更新

海畔目前提供 Android 安装包。下载、覆盖安装和版本更新都遵循同一套规则，不会动你的本地课表缓存。

  1. 下载安装包从官网下载区或 GitHub Releases 获取最新 APK；建议使用页面提供的镜像加速直链。
  2. 允许安装未知来源应用系统会提示一次，授权后即可继续安装。
  3. 覆盖安装新版本直接覆盖旧版本，课表缓存、设置与登录状态会保留。
只从官方渠道下载
请使用官网、GitHub Releases 或 Gitee 镜像。第三方站点重新打包的 APK 可能被篡改，也会因为签名不同而无法覆盖安装。

应用内也可以检查更新：进入「我的 → 检查更新」。版本号格式为 1.0.1+构建号，构建号更大的才是新版本。

02

首次登录

登录使用学校统一身份认证，过程在应用内的认证页完成，海畔不会绕过学校页面直接索取密码。

  1. 优先连接校园网校内网络会自动直连教务，速度最快，也不需要额外开通权限。
  2. 输入学号与密码按认证页提示完成验证码、短信或企业微信等多因子步骤。
  3. 等待课表导入首次登录会拉取课表与学籍信息，完成后进入首页。
公网通道需要开通
在校外使用公网通道前，需要联系管理员把学号加入准入名单；未开通时请先连接校园网登录。

设备绑定

首次登录会把学号与当前设备绑定。正常情况下换机后重新登录即可自动换绑；如果管理员关闭了自动换绑，需要先在网页端退出或联系管理员重置。

03

课表

首页默认展示当前学期的周课表。顶部可以切换周次、回到本周，也可以在学期之间切换。

周次与学期

应用会按开学时间估算当前周次；如果估算不准，手动切到正确周次即可。历史学期可以随时回看，但不会再显示日期标签。

课程与实践课

点击课程卡片可以查看课程名、教师、教室、节次与周次。没有固定节次的实践课会单独列在课表下方，不会硬塞进网格。

离线缓存

课表成功加载后会写入本地缓存。之后即使断网或认证过期，仍然可以打开上一版课表；下拉刷新会在网络恢复后重新同步。

课程颜色
同一门课在整张课表里保持同一种颜色，方便快速扫视；换学期后颜色会重新分配。
04

成绩与考试

成绩页会把全学程成绩汇总成总览，再提供单科明细，避免在多个页面之间来回查找。

成绩总览

总览包含学分绩点、加权平均分、已获学分与通过率。点击学期可以跳到该学期的课程明细；课程性质与分数区间会以图表呈现。

成绩明细

支持按学期、课程性质、是否通过筛选，也可以按课程名、课程号或教师搜索。展开单科可以查看成绩构成；本地换算的绩点会标注「估算」。

考试安排

考试页按日期排列，显示剩余天数、起止时间、考场与座位号。考前提醒可以单独开启，不影响课程提醒。

05

空教室

空教室查询按校区、楼号、周次与节次组合筛选，适合临时找自习位置。

  1. 选择查询条件先选校区与楼号，再选周次和节次；条件越具体，结果越接近实际。
  2. 查看空闲结果结果会区分可用与占用，并显示教室名称与容量等信息。
  3. 收藏常用教室收藏后会排在结果前面，下次查询不用重新找。
以现场为准
空教室数据来自教务排课，临时调课、考试占用或教室关闭不会实时反映，出门前建议再确认一次。
06

提醒与桌面组件

课程提醒依赖系统通知与精确闹钟，首次使用需要授予通知权限；Android 12 及以上还需要「闹钟与提醒」权限。

课程提醒

提醒按课表缓存提前调度，离线也会触发。点击通知会直接跳到对应课程。若系统开启了省电限制，提醒可能延迟，建议把海畔加入电池优化白名单。

桌面组件

提供今日课程与周课表两种组件。添加方式与普通 Android 桌面组件一致：长按桌面空白处 → 组件 → 海畔。

组件不刷新？
先打开一次 App 让课表完成同步；部分系统会限制后台组件刷新，重新添加组件通常可以恢复。
07

校外访问

海畔会自动判断当前网络。在校园网内直连教务；在校外时，如果已开通公网通道，会自动切换到加密中转通道。

校园网
直连，速度最快，推荐优先使用。
公网通道
需要管理员开通，速度受中转链路影响，适合临时查课表与成绩。
切换方式
自动探测，不需要手动设置；网络变化后会自动重连。
公网通道不是万能入口
学校统一认证页在校外可能要求额外的多因子验证；如果一直失败，请回到校园网完成登录，或联系管理员确认准入状态。
08

常见问题

登录一直失败，提示未开通或设备不匹配

先确认是否在校园网。如果在校外，需要管理员把学号加入公网准入名单。提示设备不匹配时，说明该学号已绑定其他设备，需要管理员重置或等待自动换绑。

课表是空的，或者周次对不上

先在课表页下拉刷新。周次为空通常是开学时间估算偏差，手动切到正确周次即可。历史学期不显示日期属于正常现象。

已经是最新版，为什么还提示更新

请对照「我的 → 关于」里的构建版本与 Release 标签。若构建版本低于标签，说明安装包确实较旧；若完全一致仍提示，请通过意见反馈附上日志。

换手机后需要重新登录吗

需要。新设备首次登录会重新完成设备认证；本地缓存不会跨设备迁移，课表会重新从教务拉取。

提醒不准时或没有声音

检查通知权限、闹钟与提醒权限，以及系统省电策略。部分国产系统需要单独允许「自启动」和「后台运行」。

怎么反馈问题

进入「我的 → 意见反馈」，应用会导出日志并附到邮件里。也可以直接发邮件到 xiuhong0327@163.com。
